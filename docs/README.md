# Documentation

This folder contains the plain-English documentation needed to understand and reproduce the dissertation pipeline.

It will include:

- `project-overview.md` — the research aim, datasets, and pipeline summary.
- `exclusion-log.md` — excluded exploratory topics and the decision criteria.
- `analytical-decisions.md` — the final primary analysis specification and the distinction between the main and alternative clustering runs.
- `data-availability.md` — which files are included in this repository, which large files are archived separately, and how they can be recreated.
- `validation-protocol.md` — the planned manual validation protocol for extracted and decontextualised rules.

The repository is organised so that code, prompts, small result tables, and documentation are public, while large raw and intermediate files are retained separately because of repository size limits.
