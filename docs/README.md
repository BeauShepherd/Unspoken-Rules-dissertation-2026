# Documentation

This folder contains the plain-English documentation needed to understand and reproduce the dissertation pipeline.

## Read in this order

1. [`project-overview.md`](project-overview.md) — research aim, data sources, pipeline, and the role of topic-level comparison.
2. [`analytical-decisions.md`](analytical-decisions.md) — the primary-analysis specification and the distinction between main and alternative runs.
3. [`exclusion-log.md`](exclusion-log.md) — source-topic exclusions and their criteria.
4. [`data-availability.md`](data-availability.md) — what is public, what is archived, and why large files are not stored in GitHub.
5. [`file-inventory.md`](file-inventory.md) — which files define the primary analysis and how future files should be named.
6. [`validation-protocol.md`](validation-protocol.md) — the blinded manual audit planned for extracted and decontextualised rules.

The repository is organised so that code, prompts, small result tables, and documentation are public, while large raw and intermediate files are retained separately because of repository size limits.
